Version 1.3.0

New screen
• Game Boy Mosaic: Turns the image into a circular-dot mosaic using the original Game Boy's green palette. Adjust the cell size and the number of colors.

Better on foldable iPhone, iPad, and Mac
• Folding or unfolding the device now keeps the current screen and its state.
• Canvas and controls switch between stacked and side-by-side layouts based on the available space, so they fit narrow split views and landscape.
• The sidebar now shows thumbnails and a clear selection highlight.

Other improvements
• A refreshed app icon.
• Fixed layout glitches when rotating or resizing, and a crash on some screens.
